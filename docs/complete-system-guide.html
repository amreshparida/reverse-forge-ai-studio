Intelligence Pipeline — Deep System Guide

How the studio turns a live enterprise web app into reverse-engineering documentation: three crawl strategies capture evidence; page AI labels each screen; a synthesis agent builds models under coverage gates; an analysis graph is indexed and chunked for specialist agents; expert analysis chunks the evidence package; the final report merges everything.

Read-only crawls Coverage-gated synthesis Typed analysis graph Six specialist personas Expert chunk merge

2. Safety invariants

Every crawl mode is a read-only observer. Unsafe controls are classified before click.

flowchart TD El[Interactive element] --> T{Text unsafe?} T -->|yes| Block[Block / paint red] T -->|no| U{URL / href unsafe?} U -->|yes| Block U -->|no| A{Agent action validator} A -->|fail| Block A -->|pass| Allow[Allowed for crawl / LLM]

Layer A — Text

Delete, submit, approve, logout, pay, send… multi-language partial match.

Layer B — URL

Logout / SSO SLO, IdP discovery, session-end hrefs.

Layer C — Act

Action validators refuse unsafe agent actions; form submit blocked.

Nav Fields Safe buttons Other UI Unsafe — never clicked

4. BFS crawler — depth-bounded link expansion

Systematic breadth-first traversal of the navigation graph. Best for predictable menu/link coverage.

flowchart TD Start([Start BFS crawl]) --> Init[queue = postLoginUrl at depth 0
visited = empty] Init --> Check{queue empty?} Check -->|yes| SessionEnd[Session-end advanced captures
OpenAPI / GraphQL / WebSocket / SSE] SessionEnd --> Done([Crawl complete]) Check -->|no| Dequeue[Dequeue url, depth] Dequeue --> Skip{url visited OR
depth greater than crawlDepth?} Skip -->|yes| Check Skip -->|no| Visit[Mark visited] Visit --> Nav[goto url unless already there
networkidle then auto-scroll] Nav --> Shots[observe + overlay = viewport shot
remove overlay = full-page shot] Shots --> Extract[extractPageData
forms / tables / nav / modals] Extract --> Safe[optional exploreSafeInteractions
up to 10 safe clicks] Safe --> Intel[extractJsIntelligence
+ advanced page captures] Intel --> Net[flush network calls for this page] Net --> Links[discoverLinks
hrefs + interaction URLs] Links --> Enq[for each safe new link
enqueue at depth + 1] Enq --> Check
Depth is hard-capped by project crawlDepth. Unsafe URLs never enter the queue.

5. Agentic crawler — observe → plan → act → validate

LLM-driven exploration for tabs, panels, and dynamic UI that BFS link graphs miss. Loop budget defaults to 150 steps.

flowchart TD Start([Start agentic crawl]) --> Loop[Observe PageState] Loop --> NewURL{URL new?} NewURL -->|yes| Cap[Capture page
shots HTML extract DB network] NewURL -->|no| PlanCheck Cap --> PlanCheck{Every 15 steps
and pages >= 3?} PlanCheck -->|yes| Plan[Planner LLM
coverageEstimate] Plan --> Cov{coverage >= 0.90?} Cov -->|yes| Stop([Stop]) Cov -->|no| Nav PlanCheck -->|no| Nav[Navigator LLM
vision overlay preferred] Nav --> Val[validateAction safety] Val --> Act[executeAction Playwright] Act --> Post[Post-action validate
optional backtrack] Post --> StopCheck{max steps OR
3x done OR nav exhausted?} StopCheck -->|no| Loop StopCheck -->|yes| Stop

Action vocabulary

click, navigate, input, select, send_keys, scroll, scroll_to_text, scroll_to_percent, open_tab, switch_tab, close_tab, back, done

Stop conditions

  • Max steps (default 150)
  • Planner coverage ≥ 90%
  • 3 consecutive done with no unvisited nav
  • Abort / all nav explored

  • Full artifact bodies
  • Full multi-MB analysis graph
